SYSTEM_SPEC.md — Multi-Rate Behavioral Stream Forecasting & Diagnostics Platform0. Non-Negotiable Agent Execution RulesRead these invariants before writing any code. Violating any rule invalidates the entire research platform:Zero Lookahead Leakage: Every feature, scaler, quantile threshold, and regime filter at step $t$ may ONLY access data with close_time_ms less than or equal to close_time_ms[t].Strict Fit/Freeze Per Fold: All scalers (RobustScaler), HMM parameters, regime labels, and ML models MUST be fit strictly inside the training fold, frozen, and applied forward-only to the test fold. Never fit any transformation on the full dataset.Never Smooth Test Regimes: Never call hmmlearn's .predict_proba() or .decode() on test data (they run backward smoothing using future observations). You MUST use the custom strictly causal forward-filter function specified in Section 6.Never Bridge Maintenance Gaps: Any rolling window, lag, or forward target that crosses a detected gap MUST output null.Domain-Agnostic Naming: Strictly use the schema column names defined in Section 2 throughout Python, SQL, and TypeScript.Scale Invariance: Never feed raw unbounded $x_t$ levels or raw unnormalized activity volumes into any model. All model inputs and targets must be log-ratios, Z-scores, percentile ranks, or volatility-normalized deltas.Deterministic Execution: Pin all random seeds (SEED = 42), sort HMM states deterministically by volatility, and pin library versions.1.
